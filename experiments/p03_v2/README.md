# Preserved P03.2-V2 scripts

The six Python files are byte-for-byte copies from the historical ignored `outputs/trunk/p03_2_v2/` directory. They preserve the original experiment entry points and known lint/format debt. Repository-wide Ruff excludes this folder intentionally. The existing production/default trunk method remains the P03.2-AUTO `hybrid`.

For authorized replay, first restore `P03-DEV` and the dataset following the [dataset guide](../../docs/dataset_setup.md). Use a separate checkout, copy these six `.py` files into `outputs/trunk/p03_2_v2/`, and start runners at the repository root. `prepare.py` derives output paths from its own location and expects the original dir layout. Avoid running `prepare.py`, `freeze.py` or the evaluators in the only copy of curated evidence. For example, `./.venv/Scripts/python.exe outputs/trunk/p03_2_v2/evaluate.py 0 10` reuses the development references. Full historical oracle regeneration additionally needs historical AUTO overlays/masks that remain local. Pickle caches are excluded from the transfer bundles; regenerate on trusted data and keep them local.

Published baseline metadata remains under `outputs/trunk/p03_2_auto/`. The development archive holds the exact AUTO source snapshot, calibration data, previous V2 development and independent results, and V3 SLIC/schema/oracle artifacts. Existing full checkpoints remain local and identified by checksum in the [artifact manifest](../../docs/team_preparation/artifact_manifest.csv). V2 C is historical. V3 frozen test identities are a separate, access-restricted archive.
