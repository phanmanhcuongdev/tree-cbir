# Dependency matrix — 03/08

All component implementations can start with canonical RGB and the mock observations in `tests/conftest.py`. The matrix describes runtime dependencies and the quality conditions needed for measurements. It leaves assignment and ownership decisions to 04/08. [Module contracts](../module_contract.md) · [Architecture](../architecture.md)

| Consumer | Required input | Shared upstream evidence | When evidence is missing or uncertain | Independent test inputs |
| --- | --- | --- | --- | --- |
| Trunk X0–X8 | RGB and trunk config | None | Return individual unreliable/unavailable geometry and invalid feature positions as needed. Positive support in one measurement does not establish quality for others. | Complete synthetic image and trunk mask, measured or uncertain base and width. |
| Canopy X9–X16 | RGB and canopy config | Optional trunk base/upper point, box, mask or quality | Localize a canopy ROI independently under the configured fallback. Invalid visibility when ROI remains untrustworthy. Confirmed leafless and unknown empty masks carry distinct states. | `trunk_case="missing"`, `foliage_case="leafless"` or `"unknown"`; independent mock ROI. |
| Branch X17–X19 | RGB and selected shared canopy ROI for X17 | Canopy ROI quality and optional foliage/trunk exclusion | Prefer a corroborated shared ROI. If unavailable, X17 is invalid; skeleton values need approved independent topology evidence. | Canopy ROI, visible branch mask and branch skeleton; optional upstream trunk. |
| Root X20–X25 | RGB and root config | Base and width with separate quality; optional trunk mask and bark evidence | Estimated search geometry remains diagnostic until supported. X22 is invalid unless a positive measured trunk-width span is available. Failed base/ROI invalidates dependent measurements, with no automatic promotion from an estimated ROI to a detected root. | Exposed roots/skeleton with `trunk_case="complete"`, `"uncertain_base"`, `"unreliable_width"`, or `"missing"`. |
| Context X26–X37 | RGB and context config | All available masks including roots, lower ROI and upstream status | Exclude known tree pixels, report incomplete evidence, and invalidate affected features when required exclusion is unreliable. Detected overlap in assembly invalidates only context. | Complete tree and `incomplete_tree=True` with partial/missing component inputs. |
| Assembly | Outputs keyed by group and carrying the required ordered IDs | Any subset of the five groups | Preserve position and validity for available components, add an invalid slice for each omitted/failed group, and reject registration errors. | Synthetic feature groups passed in shuffled order, attempted component failure, duplicate group and invalid type/shape. |
| Normalization and ingestion | Compatible 38-dimensional results with validity and provenance | Accepted manifest and consistent extraction version | Fit on valid observations. Exclude unavailable/constant dimensions from discrimination as specified. Defer active profile if compatibility or fit is inadequate. | Synthetic assembled records and frozen Min–Max artifacts. Production implementation is planned. |
| Ranking | Compatible normalized query/gallery vectors with validity | Frozen database fit plus scoring and coverage profiles | Emit explicit inadequate evidence or incompatible version outcome. Never synthesize candidate records. | Synthetic normalized vectors, weights and missingness scenarios. Production implementation is planned. |
| UI and evaluation | Service response with versioned records and diagnostics | Extraction/ranking trace; evaluation also uses held-out judgments | Display failed stage or degraded status using service diagnostics. Keep test references in evaluator only. | Service fakes and deterministic trace records. Implement UI integration after services. |

Trunk, canopy, branch, root and context tests do not import another component's concrete algorithm to create prerequisite data. An orchestrator supplies the actual upstream observation and configuration. Branch and canopy must agree on a single ROI provider for a given profile. Context and final assembly coordinate only through shared observation types. Geometry with `MeasurementQuality.ESTIMATED` must carry the actual estimate and a diagnostic source. Validity belongs to each feature, independently of the aggregate segmentation state.
