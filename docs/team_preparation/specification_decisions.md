Each row can have several classifications because a Report 1 definition can leave an implementation parameter open. **Defined by Report 1** identifies source-backed semantics or a draft rule. **Existing project decision** identifies an established contract or a prior recorded project choice. **Proposed implementation convention** gives a deterministic default for implementation design or unit fixtures. **Requires empirical calibration** means the production value must be obtained from development evidence. **Requires owner approval** flags a choice that affects interpretation or release criteria. A proposed convention or preliminary threshold carries no empirical validation. ## Normalization and ranking reference policy

This proposed policy is a worked implementation contract for A21–A23. Threshold and weight values remain release configuration requiring selection and sign-off. It generalizes the source's weighted sum without changing the five groups or adding dimensions.

1. For a frozen fit, let `A_g` be the active dimensions of group `g`, with `n_g = |A_g|`. Exclude unavailable and constant dimensions from `A_g`. Require at least one active positive-weight group and active evidence capacity in both trunk and canopy. A group with zero active dimensions has weight zero in the index profile and is shown as unavailable. No per-query or per-candidate weight renormalization.
2. For a query/gallery pair let `S_g` be the shared valid subset of `A_g` and `c_g = |S_g|/n_g`. The measured mean absolute distance is `d_g = mean_{k∈S_g} |z_qk − z_xk|` when shared evidence exists. The proposed effective distance is `D_g = (Σ_{k∈S_g}|z_qk − z_xk| + n_g − |S_g|)/n_g` for `n_g > 0`. This equals `c_g × d_g + (1 − c_g)` when `S_g` is nonempty and gives `D_g = 1` for an active group with no overlap. Keep `d_g` absent in that second case. Apply the penalty only to the score and preserve missing feature values.
3. Check eligibility before ranking. For query self-coverage use the same `A_g` with query-valid positions. For pair coverage use `C_pair = Σ_g w_g c_g`. Compare with versioned minima and apply a positive morphology-overlap gate independent of context. Set the exact gate and thresholds in A23. Require monotonic gates, so deleting validity cannot turn an ineligible candidate into an eligible one. An entirely missing group cannot improve similarity: each removed distance was at most 1, while its missing cost is 1. Full overlap reduces to the ordinary mean per group, which accounts for group size.
4. Rank eligible candidates by `D_total = Σ_g w_g D_g`, with `similarity = 1 − D_total`. Break ties by stable image ID. Query diagnostics distinguish input failure, insufficient query evidence and fewer than five eligible records. In explanations show `n_g`, `|S_g|`, measured distance where defined, effective distance, group weight and weighted contribution. Return actual comparable results with the incomplete-status policy in [R04/E05](../requirements.md#normalization-and-ranking-contract).

**Mathematical fixtures.** With fitted bounds `[2,6]`, raw 4 maps to 0.5 and raw 8 clips to 1 with an out-of-range flag. A constant fitted from valid values gives normalized 0 but contributes no ranking dimension. A dimension without valid fit values is unavailable. For a group with two active dimensions and common differences 0.2 and 0.6, `D_g = 0.4`. Hiding the second coordinate gives `D_g = 0.6`, hiding both gives `D_g = 1`. If all five groups have identical average error and full coverage, all five distances match regardless of group size. A candidate with only context overlap fails the morphology gate.
